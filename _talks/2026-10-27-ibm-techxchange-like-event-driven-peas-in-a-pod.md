## Abstract

Event-driven applications unlock performance and throughput in a scalable way. It can however be cumbersome to set up these kinds of apps, especially for developers who aren't familiar with setting up Kafka infra and the necessary configurations. We'll demonstrate how Quarkus (a modern Java stack) enables rapid development with minimal configuration: dev services start up pre-configured Kafka instances; dev mode enables live reloads and fast iterations; and dev mcp enables AI agents to build, test and debug Kafka-enabled apps. Once ready for deployment, we'll show how Confluent's Data Streaming platform enables a quick and easy turnaround to enable production behavior that performs at scale. You'll leave this session with a practical blueprint for fast, performant EDA development.

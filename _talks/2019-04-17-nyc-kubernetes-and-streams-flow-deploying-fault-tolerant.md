## Abstract

All things change constantly, and we need to get on board with streams! Kafka Streams, Apache Kafka’s stream processing library, allows developers to build sophisticated stateful stream processing applications which you can deploy in an environment of your choice. In this talk, Viktor explains the essentials of dynamic scaling and state migration in Kafka Streams.

## Abstract

You already know the SQL. What changes on a stream is the meaning: a query never finishes, a result is a changelog that keeps correcting itself, and time is something you declare in the table. This session takes the SELECT, JOIN, and GROUP BY you write every day and runs them on unbounded data in a live Flink SQL playground, growing one pipeline step by step: a stream-stream join, event-time windows and watermarks, late data, a temporal join that prices each transaction at the exchange rate valid when the card was swiped, and an impossible-travel fraud check with MATCH_RECOGNIZE. Then the same pattern becomes real-time AI on Confluent Cloud Flink, where a windowed feature and ML_PREDICT score every payment with a model before it settles. Flink speaks SQL, but it is not a database, and once that clicks you know when to stream and when batch is good enough.
